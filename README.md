# Crypto Signals Pro 🚀
### منصة احترافية لتحليل عقود العملات الرقمية الآجلة (Futures) باللغة العربية (RTL)

تطبيق ويب تقدمي (PWA) فائق السرعة ومصمم للموبايل أولاً (Mobile-First)، يعتمد على بيانات حية لحظية من Binance Futures ويوفر تحليلاً فنياً متعدد الفريمات مع حساب دقيق للأهداف ونسب التحرك وإدارة المخاطر.

---

## 🌟 الميزات الرئيسية

1. **التحليل الفني متعدد الفريمات (Multi-Timeframe Engine)**:
   - فحص وتوافق الفريمات: `1d`، `4h`، `1h`، `15m`، `5m`.
   - قياس نسبة الثقة الإجمالية (5 فريمات = 90%+، 4 فريمات = 75%، 3 فريمات = 60%).
   - توليد شرح فني باللغة العربية البسيطة والمفهومة.

2. **أهداف ونسب تحرك دقيقة (TP1, TP2, SL, R:R)**:
   - تحديد نقطة الدخول (Entry).
   - الهدف الأول (TP1) والهدف الثاني (TP2) استناداً إلى الدعوم والمقاومات ومؤشر ATR.
   - وقف الخسارة (Stop Loss) ونسبة المخاطرة إلى العائد (Risk:Reward Ratio).
   - رسم خطوط الأهداف أفقياً على شارت الشموع مع نسب التحرك المئوية.

3. **شارت تفاعلي احترافي (TradingView Lightweight Charts)**:
   - شارت شموع يابانية سريع وخفيف الوزن.
   - تحديث لحظي للشموع عبر WebSocket بدون إعادة رسم الشارت بالكامل.
   - مؤشرات مدمجة: EMA (20/50/200)، Bollinger Bands، Volume.
   - خطوط الدعوم والمقاومات المحورية.

4. **تحديثات لحظية ومصادر بيانات مجانية بدون مفاتيح API**:
   - أسعار العقود الآجلة عبر `wss://fstream.binance.com/ws/!markPrice@arr@1s`.
   - شموع حية عبر `wss://fstream.binance.com/ws/<symbol>@kline_<interval>`.
   - معدلات التمويل (Funding Rates) والفائدة المفتوحة (Open Interest).
   - مؤشر الخوف والطمع (Fear & Greed Index).
   - توفير في استهلاك البطارية عبر إيقاف WebSockets تلقائياً عند مغادرة التطبيق وإعادة الاتصال التلقائي.

5. **ماسح الفرص (Futures Scanner)**:
   - ترتيب العملات حسب قوة الإشارة وتوافق الفريمات.
   - فلاتر للاتجاه (شراء/بيع) ونسبة الثقة والحجم.

6. **دفتر صفقات متقدم (Futures Trade Journal)**:
   - تسجيل صفقات Long و Short مع الرافعة المالية والهامش وأسباب الدخول.
   - حساب فوري لـ Win Rate، عامل الربح (Profit Factor)، متوسط R Multiple، وإجمالي PnL.
   - حفظ محلي آمن في `localStorage` مع إمكانية التصدير والاستيراد (JSON).

7. **حاسبة المخاطر والرافعة المالية (Risk Calculator)**:
   - حساب حجم المركز المطلوب للحفاظ على نسبة المخاطرة (1% - 2%).
   - اقتراح رافعة مالية آمنة تمنع التصفية المبكرة قبل ضرب الوقف.
   - تحذير تلقائي إذا تجاوزت المخاطرة 2%.

8. **تطبيق ويب تقدمي (PWA)**:
   - قابل للتثبيت كأي تطبيق أصلي على أندرويد وآيفون (Add to Home Screen).
   - دعم التصفح في وضع عدم الاتصال (Offline caching عبر Service Worker).

## 🛠️ متطلبات التشغيل والتطوير

- Node.js 18+
- npm أو bun

### تشغيل التطبيق محلياً:
```bash
npm install
npm run dev
```
سيعمل التطبيق على المنفذ `http://localhost:3000`.

---

## 🚀 خطوات البناء والنشر (Deployment Guide)

### 1. بناء المشروع للإنتاج:
```bash
npm run build
```
سيتم إنشاء مجلد `dist/` يحتوي على ملفات HTML و CSS و JavaScript المجمعة وملف `sw.js` و `manifest.webmanifest`.

### 2. النشر على منصات الاستضافة:

#### أ. Vercel:
1. قم بربط مستودع Git بـ Vercel.
2. حدد إعدادات البناء:
   - **Build Command**: `npm run build`
   - **Output Directory**: `dist`
3. اضغط Deploy.

#### ب. Netlify:
1. ارفع مجلد `dist` مباشرة عبر Netlify Drop أو اربط المستودع.
2. اضبط:
   - **Publish directory**: `dist`
   - **Build command**: `npm run build`

#### ج. استضافة مخصصة / Cloud Run / Nginx:
يمكنك خدمة مجلد `dist` الثابت عبر أي خادم ويب مثل Nginx مع ضبط إعادة توجيه المسارات إلى `index.html`.
